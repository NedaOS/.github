# Fedora Setup
My automated setup for **[Fedora Everything 44](https://fedoraproject.org/misc/#everything)**, using [Ansible](https://ansible.com) and [chezmoi](https://www.chezmoi.io).

## Installation

Run the following command in your terminal:

```bash
curl -fsSL https://raw.githubusercontent.com/NedaOS/fedora-setup/main/scripts/bootstrap.sh | bash
```

**Requirements:** An internet connection and a user account with `sudo` privileges.
